## Context and scope

Link the baseline requirements/specifications/plan, this case's requirements
and source/Gold contracts. Name the domain owner, supported patterns,
unresolved decisions and unavailable capabilities.

## Implementation and evidence

1. Review source evidence and explicit keys/grain/time/units/joins.
2. Validate every BASE mapping and case contract; resolve blocking gaps.
3. Compile draft metadata/context and review deterministic differences.
4. Reuse shared engines, adding only reviewed case-specific rules if needed.
5. Test domain results and shared invariants with versioned fixtures.
6. Separately approve and prove native binding, execution, recovery,
   layout/MLV and consumer compatibility.
7. Record publication/cutover/retention decisions without inferring approval.

Replace this outline with named work, dependencies and measurable evidence.
Do not mark a skipped/native-unrun item complete.
